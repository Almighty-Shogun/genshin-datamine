# Generated Types
This package provides **all TypeScript typings** generated from the Genshin Impact datamine.

> [!NOTE]  
> These typings are **weakly typed** and were automatically generated using a custom script. They cover **every datamine file** available for Genshin Impact.

If you’re looking for **stronger, more precise typings**, check out the [**types**](../types) package. It focuses on essential data such as **characters, weapons, artifacts**, and other key game elements, rather than the complete datamine.
